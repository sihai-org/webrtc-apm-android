首个独立 Android APM 版本，基于固定 Google WebRTC revision 构建，包含官方 AEC3、NS、AGC1/AGC2 等内置处理功能。

- Android API 29+，armeabi-v7a / arm64-v8a / x86_64。
- Kotlin/JNI 包装：50 项 APM 配置、136 项 AEC3 配置；PCM16 / planar float、多通道和格式转换；运行时设置、统计、线性 AEC 输出及 AEC dump。
- native 动态库仅导出 JNI_OnLoad，附带构建信息、校验和、调试符号和依赖许可证。
- 发布工作流要求三个 ABI 编译及 ELF 检查、Android library/consumer 编译与 Lint、Android 10 x86_64 模拟器消费测试全部通过。

合成信号验证不等于真实麦克风/扬声器声学验收；两个 ARM ABI 尚需第二阶段实机闭环验证。库不控制录放设备，不接入服务器，也不提供用户自定义算法的跨 JNI C++ 插件接口。

使用：下载 AAR，核对 SHA256SUMS，以 `implementation(files("libs/webrtc-apm-android-0.1.1.aar"))` 引入。契约及示例见仓库 docs/api.md。
